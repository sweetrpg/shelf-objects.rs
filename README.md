Persistence models and API value objects for the Shelf microservice's domain: library,
wishlist, table, visibility. Pure data types - no business logic, no I/O.

Currently a scaffold - no implementation yet, no Rust consumer exists today.

## Install

```bash
cargo add sweetrpg-shelf-objects
```
